# Changelog

## 1.0.0 — 2026-10-29

- OpenCode v2 plugin for Pagey static site publishing.
- Preview public build files and publish an exact upload digest with OpenCode permissions.
- Create sites with custom subdomains, replace content at the same URL, list and inspect sites, and update title, expiry, or password protection.
- Reject common private files and credentials; keep API tokens in the server environment.
